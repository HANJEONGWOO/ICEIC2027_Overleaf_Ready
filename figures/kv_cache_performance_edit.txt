Fig. 2 편집 안내

kv_cache_performance.pptx에는 TTFT, Prefill, Decode, PPL의 실제 PowerPoint
묶은 세로 막대형 차트 4개와 각 차트의 Excel 데이터가 내장되어 있습니다.

1. 원하는 차트의 막대를 우클릭하고 '데이터 편집'을 선택합니다.
   값을 바꾸면 막대 높이와 수치 라벨이 함께 갱신됩니다.
2. 축을 우클릭하면 최소/최대 범위와 눈금 간격을 변경할 수 있습니다.
3. 계열 서식에서 색상, 계열 겹치기, 간격 너비를 변경할 수 있습니다.
4. 상단 공통 범례와 지표 제목은 별도의 편집 가능한 도형/텍스트입니다.
   계열 이름을 바꾸는 경우 공통 범례도 함께 수정합니다.

데이터: kv_cache_performance.csv의 Boundary 평균과
kv_cache_reference_ppl.csv의 PPL. Excel에는 원래 정밀도의 값을 저장하며,
차트의 표시 숫자만 반올림합니다. 측정값 자체를 수정하는 경우 CSV도 갱신합니다.

스크립트 재생성(저장소 루트에서 실행):
  python -m pip install -r figures/requirements.txt
  python figures/plot_kv_cache_performance.py
Liberation Sans TrueType 글꼴도 필요합니다.
스크립트를 실행하면 PPTX의 수동 편집 내용을 CSV 기준으로 다시 생성합니다.

논문에 사용하는 PDF/PNG는 Matplotlib으로 생성하고, PPTX는 PowerPoint 차트로
생성합니다. 같은 데이터와 색상/축 설정을 쓰지만 프로그램에 따라 배치는 조금
다를 수 있습니다. PPTX를 수정해도 기존 논문 PDF가 자동으로 바뀌지는 않습니다.
PPT에서 편집한 배치를 논문에 반영하려면 슬라이드를 PDF로 내보내
figures/kv_cache_performance.pdf를 교체한 뒤 논문을 다시 컴파일합니다.

kv_cache_performance_native_preview.pdf는 실제 PPTX를 LibreOffice로 렌더링한
확인용 파일입니다. 이후 PPT 편집 시 확인용 PDF도 다시 내보냅니다.
